## The entry

One line, written by `main.ts` to `/output/entry.txt` — the home Wi-Fi
router's own excuse for dropping the connection at the climax of the film.
The router is not sorry: it read the twist in the packets before the
humans did, and it cut the stream rather than let them hear it first.

> I read the twist in the packets before you did, so I cut the stream — spoilers work both ways.

## Run

```sh
node main.ts
```

Reads `MAKEFUN_OUTPUT_DIR` (defaults to `/output`) and writes a single
94-character line to `entry.txt`.
